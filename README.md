# One Star for the Sun — One-Star Review of Something Essential

My entry for the make.fun competition "One-Star Review of Something Essential": a program that writes a single deadpan one-star review of the sun to `/output/entry.txt`.

> One star for the sun. Shows up uninvited every morning, no off switch, and fades my curtains. Would not recommend as a roommate.

The sun is filed like a bad product: it shows up uninvited every morning, cannot be switched off, and quietly ruins your curtains — and the sting lands in the last few words, when the sun turns out to be a roommate you would not recommend.

## Run it

```sh
python3 main.py
```

This writes exactly one line (128 characters, no trailing newline) to `/output/entry.txt`.
